# Export Trade Africa

Export Trade Africa is a modern web application for an import, export, and trading company based in Lekki, Lagos, Nigeria. It connects verified Nigerian goods — agricultural commodities, solid minerals, and palm products — to global markets.

## Features

- **Mobile Responsive Design:** The platform is fully responsive, offering an optimized experience on mobile, tablet, and desktop devices.
- **Modern UI:** Built with React, Vite, and Tailwind CSS for a sleek, fast, and accessible user interface.
- **Product Catalog:** Detailed view of products including agricultural commodities, solid minerals, palm products, and consumer goods.
- **Service Offerings:** Export, import, and sourcing services cleanly presented to prospective buyers and suppliers.
- **Quote Requests:** Streamlined contact information and quick links to request quotes or become a supplier.

## Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS, Radix UI primitives
- **Icons:** Lucide React
- **Routing:** React Router

## Running the Code

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
